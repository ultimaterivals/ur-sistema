# Checklist Visual — Base Horizons

Antes de aprovar qualquer alteração visual, verificar:

## Identidade

- O site ainda parece Ultimate Rivals?
- A estética segue preto/dourado?
- A experiência parece premium?
- A interface continua mobile-first?
- O visual comunica esporte de areia?
- O visual comunica temporada?
- O visual comunica comunidade?
- O visual comunica competição?
- O visual comunica evolução?

## Estrutura

- A Home não foi reorganizada sem necessidade?
- A ordem das seções continua clara?
- O Hero continua forte?
- UR Play aparece cedo?
- Polos aparecem como comunidade?
- Ranking aparece com desejo competitivo?
- UR Legends aparece como evento aspiracional?
- UR Market aparece como vitrine?
- Quadras aparecem como base física?
- Mídia e Blog estão separados?
- Hunters aparece como metodologia?

## Copy

- A copy está clara?
- A copy é estratégica?
- O atleta entende como começar?
- Atleta sem equipe está incluído?
- Equipes estão incluídas?
- Duplas estão incluídas?
- Quartetos estão incluídos?
- N3 não é tratado como inferior?
- Benefícios não são prometidos como garantidos?
- Não existe promessa de dinheiro?
- Não existe promessa de carreira profissional?
- Regional foi removido?

## Responsivo

- Funciona em 390x844?
- Funciona em 430x932?
- Funciona em 768x1024?
- Funciona em 1366x768?
- Funciona em 1920x1080?
- Sem overflow horizontal?
- Menu mobile abre e fecha?
- Páginas abrem no topo?

## Técnica

- Build passou?
- Typecheck passou?
- Lint passou?
- Console sem erros?
- Backend preservado?
- Formulários preservados?
- Integrações preservadas?
- next-env.d.ts preservado?
- package.json preservado?
- .patch não commitado?
