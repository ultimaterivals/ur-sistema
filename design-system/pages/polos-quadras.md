# Override — Polos e Quadras

## Papel da página

Polos e quadras representam pertencimento, base física, comunidade e operação regional.

## Conteúdos obrigatórios

- Belo Horizonte.
- Betim.
- Contagem.
- Quadras parceiras.
- Comunidade.
- Calendário.
- Modalidades.
- Status de operação.
- CTA para parceria.

## UI

- Cards grandes com imagem.
- Identidade visual por polo.
- Área para quadra, endereço/referência e modalidades.
- Selo de status.
- Mapa ou lista territorial quando disponível.

## UX

- Todos os polos têm o mesmo peso.
- Quadra deve parecer base viva, não simples local alugado.
- Explicar valor para atletas, equipes, quadras e patrocinadores.

## Evitar

- Dar mais importância visual a um polo sem critério.
- Mostrar quadra como anúncio imobiliário.
- Prometer ocupação garantida.
